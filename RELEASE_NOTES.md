# MacSpaces 2.42

**2.42** is the current MacSpaces release, for macOS 15 or later on Apple silicon
and Intel.

New in 2.42:

- **Switch between Homes from the dock:** with two or more Home profiles, a new dock beside Settings has a button for each, with its own icon. Click one to switch. Pick icons in Settings → Widgets → Profiles (right-click → Icon).
- **Remove widgets from Home directly:** click a widget to select it and press Delete. An Undo button (or ⌘Z) puts it back where it was.
- **Cleaner widgets:** no more icon and name at the top of each widget; what's inside says what it is.
- **Refresh buttons spin** when you click them, so you can see the refresh happen.
