# MacSpaces 2.50

**2.50** is the current MacSpaces release, for macOS 15 or later on Apple silicon
and Intel.

Changes in 2.50:

- **Paste queue.** Turn it on from the Clipboard page or widget, copy several things, then press ⌘V over and over: each paste is the next clip, in the order you copied them or newest first. The closed Nook shows how many are left. MacSpaces asks for Accessibility only when you turn it on, so it can see ⌘V.
- **Safer clipboard history.** Private keys, access tokens and other text shaped like a credential are never recorded, along with anything a password manager marks private.
- **Lyrics that match.** Lyrics must be for the same song and artist, and timed lyrics come from the recording with the right length, so a live or radio cut no longer drifts out of sync. Intros and instrumental breaks show a rest instead of holding the last line.
- **The File Converter follows your pointer.** The highlighted format is now the one under the pointer; before, up and down were swapped.
- **Remove baskets.** Right-click a basket, or use the basket menu in an open one. The files themselves stay where they are.
- **Settings keeps its shape.** The Settings window has one size and can't be squashed.
