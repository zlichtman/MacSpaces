# MacSpaces 2.51

**2.51** is the current MacSpaces release, for macOS 15 or later on Apple silicon
and Intel.

Changes in 2.51:

- **Baskets in the Tray.** With file baskets, the Nook's Tray page shows a chip for the Tray and for each basket, so you can see and use any of them from the notch. Right-click a basket's chip to put it on the desktop or remove it.
- **Baskets stay put.** A basket parked beside the Dock folds back to exactly the same spot after you open it.
- **Remove the basket you mean.** Remove Basket in a basket's menu now lists every basket by name, so the one you're looking at is never removed by accident.
- **Cleaner Poster lyrics.** The lines behind Poster lyrics are gone.
