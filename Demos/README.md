# MacSpaces demo material

Everything here is a capture of the real app. The screenshots and the 2.x demo and
notch videos are rendered by the app's own Debug demo helpers
(`Sources/Debug/WebsiteDemo234.swift`, `WebsiteDemoCapture.swift`) with synthetic
calendar, weather, clipboard and file data, and never the camera, clipboard or files
of the Mac running them. The 1.14 video is cut from screen recordings, with the
Mirror preview replaced by the desktop wallpaper.

| Folder | Contents |
| --- | --- |
| `1.x/screenshots/` | 1.14 README images: Everforest (Catacombs by Fog Lake), KemoSabe Home and Tray, the MacSpaces theme, Appearance settings |
| `1.x/gallery/` | Earlier 1.x theme and song pairings |
| `1.x/video/` | The 1.14 demo (29 s): theme and song pairings, then the Nook, notes, widgets, Tray and Settings |
| `2.x/screenshots/` | 2.x README images: Everforest with Music, KemoSabe with Calendar, the MacSpaces theme with Weather, and Settings |
| `2.x/video/` | The 2.34 demo (15 s, three themes and dock pages) and the notch video (8 s, live activity and Drop to Tray); each with a poster and captions |
| `2.x/website/` | Website stills in KemoSabe with Maps by Yeah Yeah Yeahs playing: the Music page with lyrics, and Home (the third slide) |

Songs and cover art belong to their artists and are shown only to demonstrate the
media controls. Videos are 1600 × 884 at 60 fps; the website serves the same files.
