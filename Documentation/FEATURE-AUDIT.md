# MacSpaces 2.0 acceptance audit

## October 7 release verification (2.82)

The September table below is a historical acceptance baseline, not the current feature inventory. Version 2.82 implements the usability review and eight additions:

- Action search (default Control–Option–Space), configurable page shortcuts, keyboard pinning and Escape close. Searches MacSpaces actions and Apple Shortcuts, not arbitrary apps or disk contents.
- Shared File Tools for the converter, Tray, baskets and Finder Services. Jobs retain per-input errors and successful outputs, support cancellation/retry and expose the actual output folder. Outputs commit from staging with collision-safe reserved names; originals remain untouched.
- Tray multi-selection/drag, Space preview, Undo Remove, mixed file/text/image/link paste, sharing, retained offline references, Locate, and explicit damaged-list recovery with a preserved backup.
- Email-ready, target-size, resize/center-crop and bounded GIF options; favorites, recent actions and named saved presets. Transparent images remain transparent; compression must reduce bytes. Multi-frame images require explicit First frame extraction.
- App Intents to open a Nook page, stage files and return processed files; Finder Services and selected-file input to Apple Shortcuts. Explicit runs have Cancel and no fixed 20-second timeout.
- Opt-in folder watching for newly arriving stable files, excluding browser partial names and existing files. Six seconds of unchanged metadata is a heuristic, not a guarantee that an arbitrary writer has closed a file.
- On-device dictation with explicit Start and editable text; provider-specific Zoom/Google Meet controls that refuse unknown or ambiguous states. Meet checks the selected tab and origin; current adapters require English controls. Opening either panel does not request access.
- Music shows current-playlist order, accurately labelled as distinct from private Up Next. Spotify queue management opens Spotify; no Web API authentication is shipped because development applications are limited to five approved users. Soloist currently targets Linux. Chrome is not installed on the validation Mac.

Correctness fixes include guarded notification routing during editing, reminder-save rollback and errors, atomic/partial batch results, alpha-safe compression, explicit animated-image handling, visible Tray failures, retained missing references, long/cancellable Shortcuts, expired timer restoration and notifications requested at Start, persistent Focus phases with day reset, stale calculator-response suppression and process-start identity checks before Stop.

Validation: `Scripts/check-file-tools.sh` exercises synthetic image/PDF/batch/cancellation/collision/watcher cases and runs in CI. The isolated FeatureQA `review-regressions` scope checks reminder failure/success, timer restore, Tray undo/offline/damaged persistence, presentation guards, Music/Safari script compilation, Meet state/idempotency/ambiguity/origin, and long/cancelled process fixtures. `review-tools` renders synthetic action search, File Tools, Tray, dictation, meeting controls, timers/Focus and long music titles. Native account, microphone and actual meeting actions are not claimed as live-tested.

Dated 2026-09-27. Baseline: 1.0.0 build 10. **57 comparison rows and 38 extension entries.**

Foundation means existing source, not verified 2.0 parity. A button is not acceptance evidence.
